# RAVEN-RX Mountain Recovery Terrain

Standalone review build for the Round 2 mountain recovery scenario. It demonstrates: forward travel → infeasible turn → stop → safe backtrack → recovery junction → route B replanning → physical reroute → destination.

Open `index.html` in a modern browser. Internet is required for the Three.js CDN.

This is a review prototype and is NOT integrated into the main RAVEN repository yet. The terrain uses procedural low-poly placeholders first so the behavior can be approved before adding licensed GLB/GLTF assets.
